# Free research-workflow practice kit / 免费研究工作流练习包

Practice creating bibliographic candidates, checking short quotations against originals, and preparing an evidence table with five **explicitly fictional teaching documents**. The documents, authors, journals, situations and claims are invented; they must not be cited as real scholarship or legal authority.

- [Download the complete free ZIP](https://josephsun1854.github.io/04-literature-library/tutorials/05-practice-kit.zip)
- [Browse the original kit and its unchanged README](./practice-kit/README.md)
- [Open Literature Library](https://josephsun1854.github.io/04-literature-library/)

## 中文练习步骤

1. 下载并解压免费ZIP，或查看 `practice-kit`。保留 `01-原始材料` 中的五份MD原件和所有“教学虚构”标记。
2. `02-工作模板` 是空白元数据核验表、原句/证据表和阅读笔记。让助手把本轮成果保存在另建的 `03-工作结果`，不要覆盖原件或模板。
3. 导入文献库时，选择五份MD原件；CSV是库外的核验表，不是文献库导入格式。索引候选示例JSON也不是应用的完整备份。
4. 核对题名、作者、期刊、年份、摘要和关键词。缺失DOI与真实来源链接保留为空，不补造。普通MD导入不会自动得到内置虚构徽章，所以题名、书目和笔记里的虚构声明必须保留。
5. 在未新增笔记、清除其他筛选的固定练习状态，搜“人工复核”应得到S01、S02、S04，搜“直接引文”应得到S05，搜“不存在的练习词”应无结果。手动给S01和S04设置“算法与程序保障”主题后，应筛到这两份。
6. 回到各原件的 `[P2]`，分别记录短原句、原文件名、段落标记、自己的概括与不能推出的结论。`[P2]`是本练习的段落标记，不是PDF页码。候选卡保留“待人工核验”，逐条人工回查。

`03-工作结果示意` 供对照格式，不代表使用者已完成练习。包内核验记录来自现有核心函数对固定材料的实际运行，检查了字段、搜索与五条P2原句匹配；它**未验证网页上传流程，也不替代人工阅读或论证判断**。

## 范围与免费说明

这套自编材料作为开源文献库的免费教程配套公开。它不是付费商品，不包含增强商品包或私人研究文件；原有练习包README与文件均保持原样。原件没有真实DOI、数据、案例或期刊来源，不能用于论文引用。

文献库负责候选字段、分类、子串搜索与原件浏览。结构化证据表在库外另建；当前PDF搜索索引前12页，扫描件没有OCR，也不自动逐条提供观点出处或精确命中页码。请查看 [项目README](../README.md) 的实际能力与备份限制。

ZIP内原件与仓库目录内容相同。下载或复制教学资料不涉及上传你的研究材料；若另交给云端助手处理，需要按实际服务了解其数据处理方式。

## English note

Import the five original Markdown files, check every candidate field, and keep the fictional labels. The CSV and evidence table are external worksheets; the sample JSON is not an application backup. `[P2]` is a teaching paragraph identifier. The included check record verifies fixed-fixture core behavior, not a browser upload workflow, scholarly truth, or a user's completed review. The kit remains free.
