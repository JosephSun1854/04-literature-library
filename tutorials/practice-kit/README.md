# 五份虚构材料练习包

`01-原始材料`中的五份MD是从零编写的教学全文，不是真实论文摘要。所有作者、刊物、年份、场景、观点和摘要均为教学虚构，标题保留“【教学虚构】”。没有真实DOI或来源链接，不应补造。五份原件均包含稳定段落标记`[P1]`、`[P2]`、`[P3]`。

`02-工作模板`提供空白字段/待人工核验状态的元数据表、证据表与阅读笔记。CSV只是外部核验工作表，现有04文献库不导入该CSV；用“选择文件”导入的是五份原件MD。库外的`evidence-table.md`亦是本教程工作文件，不是04已实现的产品功能。

预期：五份材料；六个虚构作者；三种虚构刊物；全部年份2026。原件导入时只生成元数据候选，主题需人工填写。普通MD导入不会自动出现内置“虚构示例”徽章，所以题名和笔记中的虚构声明必须保留。

在未增补笔记、清除所有筛选的初始状态，搜“人工复核”应找到S01、S02、S04；搜“直接引文”应找到S05。研究主题“算法与程序保障”分配给S01/S04后，应筛得两份。

原始材料目录用于保持固定练习原件。生成的候选元数据、证据表和综述工作提纲请放在另建的`03-工作结果`目录，不覆盖原件和空白模板。后续改样例内容会改变上述检索预期。
